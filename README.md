## Dashboard

`dashboard/index.html` es un archivo único que se abre en cualquier navegador, sin conexión. Resume el caso, el mapa de riesgos, los controles, el inventario de datos, el laboratorio de sesgo y las partes interesadas con sus dilemas.

Para verlo en línea, activa GitHub Pages (Settings → Pages → rama `main`, carpeta raíz) y abre `https://ggalanc1983.github.io/magister_etica_y_gobernanza/dashboard/`.

Los datos del laboratorio de sesgo provienen de un corte sintético generado por el equipo y no describen personas reales.
